Understanding MPV codes — what 0525, 1240 and 3565 mean

Aqua Filtration System, Faridabad · 9+ years in water treatment · Updated September 2026

Short answer: An MPV code has two parts. The number gives the flow capacity and connection size, and the letters tell you the duty and mounting. So MPV 0525 STM reads as: 25NB connection, Softener, Top Mounted.

Once you can read the code, you can identify any valve from its name alone.

Breaking down the code

Take MPV 0525 STM:

PartMeaning
MPVMultiport valve
05Flow class (higher number, higher capacity)
25Connection size in NB — here 25NB
SSoftener (F would be Filter)
TMTop Mounted (SM would be Side Mounted)

The letter combinations

LettersMeaning
FTMFilter, Top Mounted
STMSoftener, Top Mounted
FSMFilter, Side Mounted
SSMSoftener, Side Mounted

Some older models simply use F or S at the end, such as MPV 0225F for a filter and MPV 0225S for a softener.

What EVOLVE signifies

EVOLVE is the automatic series. The rest of the code reads exactly the same way, so EVOLVE 0525 SSM is an automatic 25NB softener valve, side mounted.

Unions or flanges

On the largest size the code also states the connection type:

  • MPV 3565 FSM with unions — ₹7,875
  • MPV 3565 FSM with flanges — ₹12,075

Flanges cost considerably more, so specify unions unless the installation requires flanges.

A quick reference for ordering

Build the code you need in three steps:

  1. Number from your flow and vessel — 0225, 0525, 1240, 1650 or 3565
  2. First letter — F for filter, S for softener
  3. Last two letters — TM for top mount, SM for side mount

Example: a 1665 vessel softener at 3,000 LPH on a top mount vessel → 1240 + S + TM = MPV 1240 STM.

A common ordering error

People sometimes state only "MPV 0525" without the letters. That is incomplete — there are four different valves under that number, and the wrong one cannot be exchanged once fitted to a vessel.

So always give the full code, or simply tell us your vessel size, flow, duty and mounting, and we will select it.

Frequently asked questions

What does MPV 0525 STM mean?

It reads as a twenty five NB multiport valve for a softener, top mounted. The zero five is the flow class, twenty five is the connection size, S stands for softener and TM for top mounted.

What is the difference between FTM, STM, FSM and SSM?

The first letter is the duty, F for filter and S for softener. The last two letters are the mounting, TM for top mounted and SM for side mounted. So FSM is a filter valve for a side mount vessel.

What do the numbers 0225, 0525 and 1240 indicate?

They give the flow class and the connection size. 0225 is twenty NB for up to a thousand LPH, 0525 is twenty five NB, 1240 is forty NB, 1650 is fifty NB and 3565 is sixty five NB.

What does EVOLVE mean in the model name?

EVOLVE is the automatic series. The rest of the code reads exactly the same way, so an EVOLVE 0525 SSM is an automatic twenty five NB softener valve for a side mount vessel.

Why is it important to give the full code when ordering?

Because there are four different valves under each number, differing in duty and mounting. Once a valve has been fitted to a vessel it cannot be exchanged, so an incomplete code risks receiving the wrong item.
