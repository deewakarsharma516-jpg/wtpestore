KYA MILA
--------

UPLOAD KAISE KAREIN
-------------------
STEP 1 — HTML files
  Root folder ki SAARI .html files + sitemap.xml + robots.txt
  GitHub repo ki root me upload -> Replace -> Commit

STEP 2 — build-seo.js (updated)
  seo-update/build-seo.js  ->  repo ki ROOT me upload (purani replace) -> Commit

STEP 3 — workflow (updated)
  GitHub -> Add file -> Create new file
  Naam:  .github/workflows/seo-update.yml
  seo-update/.github/workflows/seo-update.yml ka content paste -> Commit
  (agar file pehle se hai to usko edit karke naya content paste kar dein)

STEP 4 — ek baar khud chalayein
  GitHub -> Actions tab -> "Update SEO pages from Google Sheet"
  -> Run workflow -> Run
  1-2 minute me green tick aayega
